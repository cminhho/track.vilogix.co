# Logistra behavior findings

- Primary navigation is pointer/keyboard driven; desktop dropdown behavior is not required for the smaller VI LOGIX information architecture.
- Hero controls use immediate hover color changes and short motion; no page-level scroll interaction is required.
- Quote/tracking controls are tab/click driven on the reference. VI LOGIX must keep its existing route-based estimator and form state instead of duplicating a decorative request form.
- Cards use restrained hover elevation/image treatment. VI LOGIX should keep borders flat and use color or slight image scale only where a card is interactive.
- Process and article sections are static content; links/buttons follow the shared focus-visible contract.
- Reduced-motion mode must suppress transform-based image or CTA transitions.
- Responsive model: multi-column grids collapse to one column on mobile; overlapping rails become in-flow blocks; process markers become stacked rows.
